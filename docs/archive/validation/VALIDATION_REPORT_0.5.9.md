# Validation Report — Agentic Trading OS 0.5.9

Status: **CANDIDATE — NOT PRODUCTION-CERTIFIED**

## Implemented

- Added an opt-in Bun/Hono local research API at `api/src/`.
- API binds only to loopback and requires a bearer secret of at least 32 characters.
- Requests have a streaming-enforced 2 MiB body limit (not dependent on Content-Length), a 30 requests/minute process-local budget that also counts failed authentication attempts, strict symbol/timeframe/OHLCV validation, and a maximum of 2,000 candles. Compressed request bodies and invalid UTF-8 are rejected.
- The API is research-only. User-supplied candles are not provider-authenticated; no trusted decision handoff or order/execution authority is issued.
- Added six Node API validator/source-contract tests, including actual stream-boundary and invalid-UTF-8 tests, plus Bun-native HTTP integration tests for authentication, bounded analysis, no-order routes, security headers, failed-auth rate limiting, and request content restrictions. The Bun-native HTTP suite is wired into CI but was not executable in this workspace.
- Version aligned to 0.5.9 in package, Tauri and Cargo manifests.

## Follow-up engineering update — 2026-10-28

### Implemented

- Replaced the API fixed-window rate counter with a fixed-memory sliding-window limiter. The ring buffer stores at most 30 admitted request timestamps, counts failed auth attempts, does not allocate per-client state, uses a monotonic production clock, clamps clock rollback fail-closed, and provides `Retry-After` on HTTP 429.
- Rejected `localhost` as a bind configuration; only literal `127.0.0.1` and `::1` are accepted. POST content type is restricted to JSON with absent or UTF-8 charset declarations.
- Corrected provenance semantics: response labels now explicitly say the service computed the canonical hash (`datasetFingerprintComputed: true`) but did not independently verify it against a trusted digest (`datasetFingerprintVerified: false`). Provider trust and decision/execution authority stay disabled.
- Added the missing Bun/Hono integration command to CI. The Bun job now runs both `bun test scripts/*.test.mjs` and `bun test api/test/app.integration.test.ts`.
